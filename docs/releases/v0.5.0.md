# v0.5.0

First release of action-devops: reusable, parallel DevOps and security checks
for GitHub Actions. One configuration workflow switches checks on or off, five
group workflows run them in parallel, and per-check scripts hold the logic.

## New features

### Three-layer layout

- **`allinone.yml`**: configuration only. It validates `mode`, calls the
  group workflows in parallel, and writes a per-check summary.
- **Group workflows**: `quality.yml`, `build-test.yml`, `iac.yml`,
  `security.yml`, `dependencies.yml`. Checks within a group run as parallel
  jobs. A group with every check off is skipped. Each group can also be called
  directly.
- **`.github/scripts/`**: one script per check. Jobs check out the scripts at
  the running workflow's own commit, so pinning `allinone.yml` pins the groups
  and the scripts too.

### Checks

| Group | Input | Default | Check |
| --- | --- | --- | --- |
| quality | `lint` | on | Super-Linter on the whole repository |
| build-test | `python` | off | Python setup, optional requirements install, test command |
| build-test | `docker` | off | Docker build; never pushes |
| iac | `terraform` | off | `fmt -check`, backend-free `init`, `validate`; never plans or applies |
| iac | `bicep` | off | Compiles every `.bicep` and `.bicepparam` file; never deploys |
| iac | `cloudformation` | off | `cfn-lint` on YAML, JSON, and `.template` files |
| security | `trivy` | on | Filesystem vulnerabilities, secrets, and misconfiguration |
| security | `iac-security` | on | Checkov on Terraform, CloudFormation, ARM, and Bicep |
| security | `codeql` | off | CodeQL `security-extended` for one language, uploaded to code scanning |
| security | `dependabot` | off | Fails on open high/critical Dependabot alerts |
| security | `dependency-review` | off | Fails on newly added high/critical vulnerable dependencies in PRs |
| security | `secret-scanning` | off | Fails on open secret-scanning alerts |
| dependencies | `versions` | on | Renovate lookup of outdated dependencies, including Actions and Terraform providers |

### Modes

- **`audit`** (default): reports findings without failing the workflow.
- **`restrict`**: any failed check fails the `summary` job, which can be used for
  branch protection.
- **`advanced`**: audit behavior plus Renovate dependency PRs on the default
  branch (`push`, `schedule`, `workflow_dispatch` only). It never auto-merges.

### Release automation

- `release.yml` publishes a GitHub release when a `vX.Y.Z` tag is pushed, using
  `docs/releases/vX.Y.Z.md` as the notes.

## Fixed

These were fixed before release, against the initial draft workflow:

- Dependabot and secret-scanning checks always failed because `gh api` rejects
  `--slurp` combined with `--jq`. They now count results with `jq`.
- Swift was accepted as a CodeQL language, but CodeQL Swift analysis needs macOS
  runners. It is no longer accepted.
- Every caller had to grant `security-events: write`, even with CodeQL off. CodeQL
  now inherits the caller's token, so only callers that enable it grant that
  permission.

## Security

- All jobs default to `contents: read` or no token permissions; only `codeql`
  inherits the caller's token.
- Checkouts never persist credentials. Third-party actions are pinned to commit
  SHAs, and Python tools to exact versions.
- `github-security-token` reaches only the alert jobs, which check out no code.
- Renovate runs with package scripts and post-upgrade commands disabled.

## Known limitations

- Not yet run end to end on GitHub Actions. The scripts and workflow wiring were
  validated locally with shellcheck and actionlint, but the first real run will
  come from a calling repository. Start with `mode: audit`.
- github.com only: the `$/` workflow references and `job.workflow_*` context
  fields it relies on are not available on GitHub Enterprise Server.
- actionlint v1.7.12 does not yet recognize `$/` references or `job.workflow_*`
  fields and reports them as errors.
- Callers must use GitHub-hosted Ubuntu runners.
- Script checkout uses the caller's token, so this repository must stay public.
- One Terraform root module and one CodeQL language per call; call again for more.

## Upgrading

First release; nothing to migrate. Pin callers to this release:

```yaml
jobs:
  checks:
    uses: diegocrew/action-devops/.github/workflows/allinone.yml@v0.5.0
```
