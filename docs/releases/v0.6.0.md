# v0.6.0

Adds Node.js, Go, .NET, and TFLint checks; lets one call cover several Terraform root modules and CodeQL languages; makes the summary show the active mode; and adds this repository's own CI.

## New features

- **`node`, `go`, `dotnet`** (in `build-test.yml`, off by default): set up the toolchain and run a trusted build/test command. New inputs: `node-version` (`24`), `node-command` (`npm ci && npm test`), `go-version` (empty reads `go.mod`), `go-command` (`go vet ./... && go test ./...`), `dotnet-version` (`10.0.x`), `dotnet-command` (`dotnet test`).
- **`tflint`** (in `iac.yml`, off by default): runs TFLint in each Terraform root module, using its `.tflint.hcl` if present. New input `tflint-version` (`v0.65.0`).
- **Multiple Terraform roots**: `terraform-directory` accepts a comma- or newline-separated list. Every root is checked even if one fails, and the job summary lists each root's result.
- **Multiple CodeQL languages**: `codeql-language` accepts a comma- or newline-separated list. Each language runs as a parallel job; `codeql` fails if any language does not succeed, and its job summary lists each language.

## Changed

- This repository now passes its own checks: `.github/linters/` sets a Black-compatible Ruff line length, a narrowly scoped Checkov skip, and JSCPD excluding workflow YAML; `.editorconfig` sets 2-space `shfmt` formatting.
- `renovate-report.py` also prints each update and lookup error to the job log, not only to the job summary.
- Group workflows that can do so set top-level `permissions: {}`, and `ci.yml` calls `allinone.yml` with `$/`.
- The `summary` job shows the active mode and its policy, highlights failed and cancelled results in bold, marks failures tolerated in `audit` or `advanced` mode as tolerated rather than passed, and lists failed checks.
- The security group's CodeQL check is now three jobs: `codeql-languages` (validation), `codeql-analyze` (one per language), and `codeql` (result). The `codeql` output and summary row are unchanged.
- `README.md` documents platform requirements (github.com only, hosted Ubuntu runners, runner 2.336.0+) and `dependency-review` behavior on non-PR events.

## Security

- TFLint receives the read-only `GITHUB_TOKEN` only while downloading plugins, not while running them.
- New setup actions are pinned to commit SHAs: `actions/setup-node` v7.1.0, `actions/setup-go` v7.0.0, `actions/setup-dotnet` v6.0.0, `terraform-linters/setup-tflint` v6.3.2. Go and Node.js dependency caching is off.
- `actions/dependency-review-action` is updated from v4 to v5.0.0, which runs on Node.js 24 and needs Actions runner 2.327.1 or newer.

## Upgrading

No changes are required: every new check is off by default, and single values for `terraform-directory` and `codeql-language` behave as before. Branch protection rules that name the old single `codeql` job inside the security group should still match, because the result job keeps that name.
