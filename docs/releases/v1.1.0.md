# v1.1.0

Improved validation, IaC scan coverage, and failure reporting for the action and reusable workflows.

## Changed

- Checkov now scans GitHub Actions workflows alongside Terraform, CloudFormation, ARM, and Bicep, and reads the existing `.github/linters/.checkov.yaml` configuration.
- Direct calls to grouped reusable workflows validate `mode` before running checks.
- Renovate uses the version 44 release line, and Trivy is pinned to v0.76.1.
- CI exercises restrict mode and verifies that the action tolerates controlled failures in audit mode and propagates them in restrict mode.
- Added Python, shell-script, and workflow regression tests.

## Fixed

- Quoted Checkov's comma-separated framework argument to resolve ShellCheck SC2054 and restore the CI lint job.
- Checkov reports when no supported files are scanned and preserves scanner failures when output is logged.
- Dependency reporting surfaces missing Renovate reports and runs after failed lookups instead of silently omitting results.
- Release publishing validates the release tag and release-notes index entry.

## Upgrading

Update action or reusable-workflow references to `@v1.1.0`. No input changes are required. Direct workflow callers must use a supported mode: `audit`, `restrict`, or `advanced`.
